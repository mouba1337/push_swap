# push_swap

A 42 project focused on sorting integers using two stacks and a limited set of operations.

The goal is to sort the input using as few operations as possible.

## What I learned

* Sorting algorithms
* Stack-based data structures
* Algorithm optimization
* Input parsing and validation
* Complexity and operation count

## Usage

```bash
make
./push_swap 4 2 1 3
```

The program outputs the sequence of stack operations required to sort the numbers.

## Language

C
